# ADR 0004: 公庫の業種別経営指標（原価率・人件費率）は入力に使わず照合だけに使う

## 背景

v5 は原価率 33%・人件費率 34% を税抜売上に掛けて費用を出していた（spec 3.2-5、3.3）。この比率の元統計は確認されていなかった。

再検証で、日本政策金融公庫「小企業の経営指標調査」2025 年度の酒場・ビヤホール（調査対象 212）を確認した（FND-9）。

- 売上高総利益率 67.8%（原価率 32.2%）、人件費対売上高比率 32.2%、売上高営業利益率 平均 -1.8%（黒字かつ自己資本プラス企業平均 4.4%）
- 売上高は原則として消費税を含む
- 人件費は役員報酬・退職金・福利厚生費を含む
- 対象は公庫が 2025 年 4〜12 月に融資した法人企業

## 決定

- 費用は積み上げ（シフト人件費・食材と飲料の原価・家賃・その他）で出す
- 公庫の比率は `data/benchmarks/jfc_2025_izakaya.yaml` に定義つきで置き、推計結果を公庫の定義（税込売上が分母、人件費に店主の労働対価を含める）に換算して比べるだけに使う
- レポートと画面には「業種平均と比べてどこが外れているか」を出し、外れていることを誤りとは扱わない

## 捨てた案

- **公庫の比率を売上に掛ける**: 分母（税込）と人件費の範囲（役員報酬込み）が違い、母集団も融資先法人に偏る
- **v5 の 33%／34% を使い続ける**: 出典が確認できない

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: 参照する調査年度・業種（2 年ごとに更新される。次回は 2027 年度調査）
- **壊すと危ない**: 比較の前に定義を揃える換算。揃えずに比べると、店主の労働対価の分だけ利益率が高く見える
